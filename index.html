Important:

There is no Ray Serve replica layer here.

Kubernetes scales the application Pods themselves, typically using an HPA based on CPU, memory, or custom/external metrics.
Example:
Pod 1 receives traffic → load increases → HPA decides to scale → Pod 2 starts → Service sends new requests to both Pods.
Ray vs Kubernetes 🔵 Ray Serve: replicas inside Ray cluster 🟢 Kubernetes: application Pods 🟠 Waiting: requests not currently processed
Educational visualization — actual HPA scaling depends on configured metrics, target utilization, cooldowns, scheduling and available cluster/node capacity.
